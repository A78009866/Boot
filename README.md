# عشر ثوانٍ — فيديو إلى تلغرام

صفحة ويب واحدة: تفتحها → تسمح بالكاميرا والميكروفون → **تسجّل 10 ثوانٍ فقط وتتوقف تلقائيًا** → تعاين المقطع → ترسله إلى محادثتك على تلغرام عبر بوت. المشروع مبني على **Next.js** ومهيأ للنشر على **Vercel** مباشرة.

---

## ما الذي تحتاجه بالضبط؟

| # | المتطلب | إلزامي؟ | ملاحظات |
|---|---------|---------|---------|
| 1 | **بوت تلغرام + التوكن** | ✅ نعم | إنشاء البوت مجاني وبدقيقة واحدة عبر @BotFather |
| 2 | **`chat_id` الخاص بك** | ✅ نعم | هو معرّفك `6519532861` — لكن لا يعمل إلا بعد أن تضغط **Start** داخل البوت مرة واحدة |
| 3 | حساب Vercel (مجاني) | ✅ للاستضافة | HTTPS إلزامي لأن المتصفح لا يسمح بالكاميرا على HTTP |
| 4 | رمز دخول اختياري `ACCESS_CODE` | ⭐ مستحسن | بدون رمز، أي شخص يملك رابط الصفحة يمكنه إرسال فيديوهات إلى تلغرامك |
| 5 | Redis أو قاعدة بيانات | ❌ لا | غير مطلوب — الفيديو لا يُخزَّن |

### هل تحتاج لصنع بوت؟ **نعم**

تيليجرام لا يسمح لأي خادم بإرسال رسائل إلى حسابك مباشرة باسمك (هذا يتطلب MTProto وحسابًا فعليًا، وفيه خطر حظر). الطريقة الرسمية والآمنة هي **Bot API**: تنشئ بوتًا، وتكون أنت من يضغط Start عليه، فيصبح البوت قادرًا على مراسلتك. الفيديو سيصل من **اسم البوت**، والمستخدمون الآخرون لا يستطيعون الكتابة إليه (إلا إذا أضفت عنوانًا له أو شاركته).

## 1) إنشاء البوت (دقيقة واحدة)

1. افتح تلغرام وابحث عن **@BotFather** (الحساب الموثّق بالعلامة الزرقاء).
2. أرسل `/newbot`.
3. اختر اسمًا للبوت (مثال: `عشر ثوانٍ`)، ثم اختر اسم مستخدم ينتهي بـ `bot` (مثال: `TenSecondsDZ_bot`).
4. سيرسل لك BotFather رسالة فيها التوكن بالشكل:
   ```
   123456789:AAH...xyz
   ```
   هذا هو **`TELEGRAM_BOT_TOKEN`**. لا تشاركه مع أحد ولا تضعه في الكود.
5. افتح البوت الذي أنشأته من الرابط الذي سلّمه لك BotFather واضغط **Start** (أو أرسل `/start`). هذه الخطوة ضرورية جدًا، وإلا سيفشل الإرسال برسالة `chat not found`.

## 2) التأكد من `chat_id`

معرّفك هو `6519532861` (كما ذكرت). للتأكد، بعد ضغط Start على البوت:

```bash
curl "https://api.telegram.org/bot<التوكن>/getUpdates"
```

ابحث في الناتج عن `"chat":{"id":6519532861`. إذا ظهر فالمعرّف صحيح.

---

## 3) النشر على Vercel

### الطريقة الأسهل (بدون سطر أوامر)

1. ارفع محتويات هذا المجلد إلى مستودع **GitHub** جديد (خاص أو عام).
2. ادخل إلى [vercel.com](https://vercel.com) → **Add New… → Project** → اختر المستودع → **Import**.
3. Vercel سيتعرّف تلقائيًا على Next.js. لا تغيّر أي إعداد في البناء.
4. قبل الضغط على Deploy، افتح **Environment Variables** وأضف:

   | الاسم | القيمة | إلزامي |
   |-------|--------|--------|
   | `TELEGRAM_BOT_TOKEN` | التوكن من BotFather | ✅ |
   | `TELEGRAM_CHAT_ID` | `6519532861` | ✅ |
   | `ACCESS_CODE` | رمز سري من اختيارك (مثال: `dz-2026-x9f`) | ⭐ مستحسن |
   | `CAPTION_TIMEZONE` | `Africa/Algiers` | اختياري |

5. اضغط **Deploy**. بعد دقيقة ستحصل على رابط مثل `https://video10-telegram.vercel.app`.

> إذا أضفت/غيّرت متغيرات بيئة بعد النشر، أعد النشر (**Deployments → ⋯ → Redeploy**) لكي تُقرأ القيم الجديدة.

### الطريقة عبر سطر الأوامر

```bash
npm i -g vercel
vercel            # نشر تجريبي
vercel --prod     # نشر نهائي
```

ثم أضف المتغيرات من لوحة Vercel أو عبر:
```bash
vercel env add TELEGRAM_BOT_TOKEN
vercel env add TELEGRAM_CHAT_ID
vercel env add ACCESS_CODE
```

## 4) التشغيل محليًا

```bash
npm install
cp .env.example .env.local     # ثم عدّل القيم
npm run dev
```

افتح `http://localhost:3000`. ملاحظة: الكاميرا تعمل على `localhost` لكنها **لا تعمل** على `http://` لأي عنوان آخر (هذا قيد المتصفح) — استخدم HTTPS أو نفقًا مثل `ngrok`.

## كيف يعمل المشروع؟

```
app/
├─ page.tsx                 → الصفحة (بطاقة التسجيل)
├─ layout.tsx               → إعدادات الصفحة (عربي RTL، منع الفهرسة)
├─ globals.css              → التنسيقات
├─ api/
│  ├─ config/route.ts       → يخبر الواجهة هل يلزم رمز دخول وهل الخادم مهيأ
│  ├─ verify-code/route.ts  → التحقق من رمز الدخول
│  └─ send/route.ts         → استقبال الفيديو وإرساله إلى تلغرام
components/
└─ Recorder.tsx             → الكاميرا، MediaRecorder، العدّاد، الإيقاف التلقائي، المعاينة، الإرسال
```

**التدفق:**

1. الصفحة تطلب `/api/config` لمعرفة إن كانت محمية برمز.
2. عند الضغط على «ابدأ التسجيل» تطلب `getUserMedia` (كاميرا + ميكروفون).
3. `MediaRecorder` يبدأ التسجيل، ويُضبط مؤقّت يوقف التسجيل **تلقائيًا عند 10.000 ثانية** (`setTimeout` منفصل عن عدّاد العرض لضمان الدقة).
4. يمكن للمستخدم الإيقاف مبكرًا بزر «إيقاف وإرسال الآن»، أو حذف المقطع وإعادة التسجيل (بتأكيد).
5. عند الإرسال: `FormData` تحتوي الملف + المدة + الأبعاد → `POST /api/send`.
6. الخادم يتحقق من الحجم والمدة، ويحوّل WebM إلى MP4 إن لزم، ثم يرسل عبر `sendVideo` إلى Bot API. إن رفض تيليجرام اعتباره فيديو، يُرسَل كملف `document` بدلًا من الفشل.
7. الفيديو لا يُكتب على القرص ولا يُخزَّن — يمر في الذاكرة فقط.

## ملاحظات مهمة

### صيغة MP4
- **Safari (macOS/iOS)** يسجّل `video/mp4` (H.264/AAC) مباشرة ✅
- **Chrome الحديث (126+)** يدعم `video/mp4` إن توفّرت مُرمِّزات النظام ✅
- **Firefox وبعض إصدارات Chrome** تسجّل `video/webm` فقط → الخادم يحاول تحويله إلى MP4 عبر `ffmpeg-static` (مضمّنة في `optionalDependencies`)، وإن فشل التحويل يُرسل الملف بصيغة WebM مرفقة كـ document.
- للتحويل على Vercel بضمانة أعلى، عيّن المتغير `FFMPEG_PATH` لمسار ثنائي ffmpeg إن استخدمت صورة/بيئة مخصّصة.

### حدود يجب معرفتها
- **حجم الطلب على Vercel:** الحد الأقصى 4.5MB لكل طلب. تسجيل 10 ثوانٍ بجودة 720p بمعدل 2.5Mbps ≈ 3MB، وهو داخل الحد. إذا رفعت الجودة (1080p أو bitrate أعلى) فقد تصل إلى 413. الحل: خفّض `videoBitsPerSecond` في `components/Recorder.tsx` أو استخدم رفعًا مباشرًا إلى تخزين خارجي.
- **مدة الدالة:** `maxDuration = 60` ثانية — كافية لرفع 3–10MB إلى تلغرام.
- **حد البوت للإرسال:** 50MB للملفات عبر Bot API. المشروع يحدّ نفسه عند 45MB.
- **الكاميرا تتطلب HTTPS** (أو localhost).
- **عدّاد الدقة:** بعض المتصفحات قد تنتج ملفًا أطول قليلًا من 10 ثوانٍ بسبب تأخير بدء الترميز؛ المدة المعروضة في الرسالة تُحسب من زمن التسجيل الفعلي وتُقصّ عند 10.

### الأمان
- ضع `ACCESS_CODE` دائمًا إذا كان الرابط سيُشارك. بدونه أي شخص يمكنه إغراق محادثتك بالفيديوهات.
- التوكن موجود في متغيرات بيئة Vercel فقط، ولا يصل إلى المتصفح إطلاقًا.
- الصفحة تحمل `robots: noindex` حتى لا تظهر في محركات البحث.
- لا تحفظ الفيديوهات على الخادم، ولا تُسجَّل إلا بعد إذن صريح من المستخدم للمتصفح.

### إذا ظهرت أخطاء
| الخطأ | السبب | الحل |
|-------|-------|------|
| `chat not found` | لم تضغط Start داخل البوت أو `chat_id` خاطئ | افتح البوت واضغط Start، وتأكد من الرقم |
| `Unauthorized` | التوكن خطأ أو فيه مسافة | أعد نسخه من BotFather، وتأكد من عدم وجود فراغات |
| `413 FUNCTION_PAYLOAD_TOO_LARGE` | الفيديو أكبر من 4.5MB | خفّض الجودة/الـ bitrate |
| الكاميرا لا تعمل | الصفحة على HTTP أو الإذن مرفوض | استخدم HTTPS واسمح بالكاميرا |
| `WebM` يصل بدل `MP4` | المتصفح لا يدعم تسجيل MP4 وffmpeg غير متاح | ثبّت `ffmpeg-static` (يثبَّت تلقائيًا مع `npm install`) أو استخدم Safari/Chrome حديثًا |

## تخصيص سريع

- **مدة مختلفة:** غيّر `MAX_SECONDS` في `components/Recorder.tsx` (وحدّد `maxDuration` في API إن زادت كثيرًا).
- **كاميرا خلفية على الجوال:** غيّر `facingMode: 'user'` إلى `'environment'` في `startRecording`.
- **جودة أعلى:** ارفع `videoBitsPerSecond` إلى `4_500_000` (راقب حد 4.5MB).
- **نص الرسالة:** عدّل `buildCaption` في `app/api/send/route.ts`.
- **إرسال إلى عدة محادثات:** كرّر `chat_id` مفصولًا بفواصل في متغير البيئة وفكّكه في الخادم.
