# عشر ثوانٍ — معاينة ريلز + تسجيل سيلفي + إرسال إلى تلغرام

صفحة واحدة تعمل كـ **تجربة ريلز**: عند مشاركة الرابط في واتساب/تلغرام/فيسبوك تظهر **صورة السيارة** كمصغّرة، وعند فتح الرابط تظهر الصورة مع زر تشغيل، وبضغطة واحدة تفتح **الكاميرا الأمامية** وتبدأ التسجيل فورًا لمدة **10 ثوانٍ**، مع **فيديو السيارة كخلفية** لكاميرا السيلفي، ثم يُرسل المقطع إلى تلغرام.

## ما الذي يعمل بالضبط؟

1. **المشاركة**: أي رابط على Vercel => وسوم Open Graph تُوَلَّد ديناميكيًا مع دومين المخدّم الحقيقي (عبر `x-forwarded-host`)، فتظهر صورة السيارة كمصغّرة مع إمكانية تشغيل معاينة الفيديو في التطبيقات الداعمة (تلغرام، واتساب ديسكتوب، ديسكورد…).
2. **فتح الرابط**: صفحة كاملة الشاشة تعرض صورة السيارة أنيقة مع زر تشغيل نابض. الخلفية تُسخَّن مسبقًا في الكاش.
3. **بعد الضغط**: تُفتح الكاميرا الأمامية ويبدأ التسجيل مباشرة (بلا خطوة ثانية)، ويظهر بداخله:
   - فيديو السيارة كخلفية كاملة الشاشة (9:16، 720×1280)
   - كاميرا السيلفي في **بطاقة بيضاء بزوايا مستديرة** أسفل الشاشة (قابلة للتخصيص)
   - عدّاد تنازلي 10 → 0 وشارة REC وشريط تقدّم
4. **الإيقاف التلقائي** عند 10.000 ثانية بالضبط، ثم معاينة المقطع مع أزرار الإرسال/إعادة التسجيل.
5. **الإرسال**: يمر الملف من الخادم إلى تلغرام ويصل كفيديو مع تعليق (المدة/الحجم/التاريخ). لا يُخزَّن على الخادم.

## ⚠️ ملاحظة مهمة عن «التشغيل التلقائي للفيديو عند فتح الرابط»

هذا القيد من المتصفحات نفسها وليس من المشروع:

| المحاولة | النتيجة |
|----------|---------|
| تشغيل فيديو بصوت تلقائيًا عند الفتح | ❌ ممنوع في كل المتصفحات الحديثة |
| تشغيل فيديو **صامت** تلقائيًا | ✅ مسموح، لكن لا يمكن بدء **الكاميرا** تلقائيًا |
| فتح الكاميرا وبدء التسجيل تلقائيًا | ❌ ممنوع تمامًا بدون لمسة/ضغطة من المستخدم (سياسة `getUserMedia`) |

لهذا اعتمدنا أفضل تدفّق ممكن: **صفحة غلاف شبيهة بالريلز مع فيديو خلفية صامت + زر تشغيل واحد** ينفّذ كل شيء فورًا. هذا هو الحل المعياري الذي تستخدمه كل منصات التسجيل على الويب.

> يمكن جعل الخلفية **فيديو يتحرك تلقائيًا (صامتًا)** خلف زر التشغيل بدل الصورة الثابتة: استبدل `<img>` بـ`<video autoPlay muted loop playsInline poster=...>` في `components/HomeClient.tsx`. يعمل في كل المتصفحات لأن الصوت مكتوم.

## إنشاء البوت والنشر على Vercel

### 1) البوت (مرة واحدة)
1. افتح **@BotFather** → `/newbot` → اختر الاسم واسم المستخدم.
2. انسخ التوكن `123456789:AAH...`.
3. **افتح البوت واضغط Start** (بدونها: خطأ `chat not found`).
4. معرّفك `6519532861` = `TELEGRAM_CHAT_ID`.

### 2) النشر
1. ارفع المجلد إلى GitHub → [vercel.com](https://vercel.com) → **Add New → Project** → Import.
2. أضف متغيرات البيئة:

   | الاسم | القيمة | إلزامي |
   |-------|--------|--------|
   | `TELEGRAM_BOT_TOKEN` | التوكن | ✅ |
   | `TELEGRAM_CHAT_ID` | `6519532861` | ✅ |
   | `ACCESS_CODE` | رمز سري (مثال `dz-2026-x9f`) | ⭐ مستحسن |
   | `NEXT_PUBLIC_SITE_URL` | `https://your-app.vercel.app` | اختياري (يُستنتج تلقائيًا) |
   | `CAPTION_TIMEZONE` | `Africa/Algiers` | اختياري |

3. Deploy. لاحقًا: إن غيّرت المتغيرات أعد **Redeploy**.
4. بعد النشر، جرّب الرابط في **واتساب** أو **تلغرام** لرؤية المصغّرة. إن ظهرت قديمة، أضف `?v=2` لتجديد الكاش في التطبيق.

### 3) محليًا
```bash
npm install
cp .env.example .env.local
npm run dev
```
ملاحظة: الكاميرا تعمل فقط على `https` أو `localhost`.

## التخصيص السريع

### تغيير ترتيب الطبقات (الخلفية والكاميرا)
في `lib/compositor.ts`:
```ts
const LAYOUT: Layout = 'pip';    // فيديو السيارة خلفية + كاميرا في بطاقة
// const LAYOUT: Layout = 'blend'; // مزج شبح بين الكاميرا والفيديو
```

### تغيير موضع/حجم بطاقة السيلفي
```ts
const PIP_WIDTH_RATIO = 0.46;   // عرض البطاقة نسبةً لعرض الفيديو
const PIP_BOTTOM_RATIO = 0.06;  // المسافة من الأسفل
const PIP_RADIUS = 34;          // استدارة الزوايا
```

### استبدال فيديو الخلفية
1. ضع ملفك في `public/` (يفضَّل 720×1280، 10 ثوانٍ، H.264).
2. أنشئ نسخة WebM احتياطية.
3. حدّث `HomeClient.tsx`:
```tsx
<Recorder autoStart fxVideoUrls={['/my-video.mp4', '/my-video.webm']} />
```

### استبدال صورة المصغّرة
- `public/og.jpg` (1200×630) و`public/poster-9x16.jpg` (720×1280).

### مدة مختلفة
- `MAX_SECONDS` في `components/Recorder.tsx`
- مدّة فيديو الخلفية يجب أن تطابقها تقريبًا (أو يبقى آخر إطار).

## حدود تقنية يجب معرفتها

| الحد | القيمة | الأثر |
|------|--------|-------|
| حجم الطلب في Vercel | 4.5MB | تسجيل 720p/10s ≈ 2.5–3MB ✅ (المزج يرفع الحجم قليلًا؛ إن اقتربت من الحد خفّض `videoBitsPerSecond`) |
| مدة دالة Vercel | 60s | كافية للرفع إلى تلغرام |
| حد تلغرام للبوت | 50MB | المشروع يحدّ نفسه عند 45MB |
| كاميرا | HTTPS أو localhost | إلزامي |
| H.264 في المتصفح | غير مدعوم في بعض نسخ Chromium على Linux | لذلك أضفنا WebM احتياطيًا للتسجيل وفيديو الخلفية |

### أخطاء شائعة
| الخطأ | الحل |
|-------|------|
| `chat not found` | اضغط Start في البوت، وتأكد من `6519532861` |
| `Unauthorized` | التوكن خطأ أو فيه فراغ |
| `413 FUNCTION_PAYLOAD_TOO_LARGE` | خفّض `videoBitsPerSecond` |
| الصورة المصغّرة لا تظهر | أعد نشر Vercel، وجرّب `?v=2`، وتأكد أن الرابط `https` |
| الكاميرا لا تفتح | الصفحة يجب أن تكون HTTPS، والمتصفح يحتاج إذنًا |

## الخصوصية
- الفيديو لا يُكتب على القرص ولا يُخزَّن — يمر في ذاكرة الدالة إلى تلغرام.
- التوكن في متغيرات بيئة الخادم فقط.
- الصفحة `noindex` كي لا تظهر في محركات البحث.
- ضع `ACCESS_CODE` إذا شاركت الرابط لتجنّب إرسال الآخرين إلى محادثتك.
